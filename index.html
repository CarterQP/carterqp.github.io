1. Introduction

This project implements a REST API using PHP, MySQL, and Nginx.

Features:

  • REST architecture
  • Secure endpoints with Bearer tokens
  • Works locally via Nginx + PHP-FPM
  • Can be containerized using Docker

2. Install MySQL

  1. Download the MySQL Installer.
  2. During setup, set a root password.
  3. Download MySQL Workbench.
  4. Launch MySQL Workbench → Connect as root.
  5. Create the database:

CREATE DATABASE musicdb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; USE musicdb;
